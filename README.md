---

## Project Overview

The AI-Powered Travel Planner Agent is an intelligent multi-agent application developed using **IBM Bob**, **IBM Granite**, and **IBM Cloud**. The system helps users create personalized travel plans based on their destination, budget, travel duration, and preferences.

The application generates customized itineraries, recommends hotels and transportation, estimates travel expenses, and provides useful travel tips through an AI-powered conversational interface.

---

## Problem Statement

Planning a trip requires searching multiple websites for hotels, transportation, tourist attractions, restaurants, and travel tips. This process is time-consuming and often results in inconsistent information.

This project solves this problem by providing a single AI-powered assistant capable of generating personalized travel plans using IBM Bob and IBM Granite.
